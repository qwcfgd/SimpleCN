# 报文监视、ASC/BLF 导出与图像观测

本次实现使用原生 Qt Widgets / QPainter，兼容 Qt 5、Qt 6；程序运行不需要 Python、Qwt 或 QCustomPlot。

## 报文监视

- 保留三个独立列。t 控制系统时间，rt 控制自记录开始为 0 ms 的时刻，dt 控制相邻记录时间差 / ms。初始仅勾选 rt；rt 以毫秒保留六位小数，例如 1234.567890。报文和展开信号均左对齐。
- “绝对时间/ms”按用户确认的定义显示相邻记录时间差，并非 Unix 时间戳。显示模式切换不重新计时；清空监视后重新起算。
- 默认不勾选“滚动显示”，每条记录追加至末尾；勾选后按软件通道、CAN/LIN、标准/扩展 ID 原位更新。“跟随”只对追加模式生效。
- 每个 HEX 字符为一个 4 bit 半字节。连续相同的同 ID 更新使其逐帧变灰，第 10 帧达到灰色；该半字节发生变化时立即恢复默认色。其他 ID 的更新不推进颜色计数。
- 当前通道导入 DBC/LDF 后，滚动模式下可展开匹配报文，查看信号名称、原始值、信号值、单位。非活动复用分支、无响应和错误数据不显示为有效旧值。
- 导出使用独立的最近 10,000 条历史缓存，不受滚动合并、筛选、时间列显隐或展开状态影响。导出不是整场测量的无限记录器。

## 导出

“导出”提供 ASC、BLF、CSV，默认 BLF。默认文件名为 Qt-GeneralController_<软件通道>_<本机用户名>_<开始记录时间>。ASC 的时间以秒表示、使用 absolute（相对测量起点的累计时间），文件头保存起始系统时间；BLF 对象使用纳秒时间戳，输入数据当前精度为微秒。

原生写入器覆盖经典 CAN 标准/扩展帧、RTR、CAN FD、LIN 普通帧、LIN 无响应和接收错误。BLF 使用 LOGG 文件头、LOBJ 事件和 zlib 容器。软件通道映射为稳定的正整数编号，并在文件内保存映射说明。BLF 的 ANSI 备注字段对非 ASCII 字符使用可逆的 Unicode 转义。

BLF 保留 LIN 无响应/错误事件类型及附加状态文字；ASC 中无法确认通用语法的 LIN 错误状态写为注释，正常 LIN 帧采用 testsrc/test.asc 的 L<通道> 格式。发送请求、模拟事件与硬件回读的来源在模型中独立保存，真实发送请求仅写为 ASC 注释或 BLF 应用文本，不作为可回放总线帧；硬件回读作为正常总线记录导出一次。没有回显时，未确认请求仍保留在注释与 CSV 中。

导出层支持 CAN FD，但当前硬件功能范围仍限于经典 CAN；这不增加 CAN FD 硬件采集能力。CSV 保留原表头和公式注入防护。

## 图像观测

信号发送页“通信配置…”右侧的“图像…”打开非模态窗口。每个软件通道独立管理窗口；关闭窗口后再次打开会保留本次会话选择。

左侧右键“添加信号…”或使用底部按钮，从该通道数据库选择信号。选择器可按报文名、ID、信号名筛选；Shift 多选、Delete 删除。右键可修改所选信号颜色；自动配色优先选取与已有颜色差异较大的颜色。信号与曲线窗格初始比例为 3:7，左侧保留信号名称、原始值、y、dy。

| 展示模式 | 行为 |
| --- | --- |
| All | 显示已添加的全部信号 |
| Marked | 仅显示列表选中信号 |
| GrayNoMarked | 全部显示，未选中信号变灰 |

| 坐标模式 | 行为 |
| --- | --- |
| Fit | 共用数值范围，Y 轴单位采用最后选定的可见信号；不在不同物理单位间自动换算 |
| arrange | 每个可见信号上下独立排列，共享时间范围，分别缩放 Y 轴 |
| All | 共用时间轴及绘图区，选中信号的独立 Y 轴从左至右排列；未选中曲线仍按自己的范围绘制 |

滚轮位于 X 轴时缩放时间，位于 Y 轴时缩放对应数值范围，位于图内时缩放 XY。关闭光标后可拖动平移；“适应数据”恢复显示全部缓存数据，“跟随最新”跟随新采样。多信号 arrange 和多轴 All 超出窗口时可滚动浏览。

y 列始终显示；未启用光标时为最新信号值，启用光标后为光标处信号值。差分光标启用后额外显示 dy：
- C1、C2 是全部信号共用的两个时间位置，可拖动或输入时间。
- 每个信号独立计算 y = y(C1)，dy = y(C2) - y(C1)，同时显示多个信号的差值。
- 两采样点之间采用线性插值；恰好落在采样点时保留原始精确文本。不同单位的两个值不计算差分。
- 同一信号相邻有效采样间隔大于 5 s 时断线；恰好 5 s 保持连接。空档、错误/无效采样、非活动分支和未覆盖时间显示“—”，不外推。
- 数组、非数值换算结果显示状态说明，不伪造数值曲线。

采样直接订阅逐帧事件，包含同一批次中的中间帧，并独立于监视窗口的 LIN RxD 显隐。发送请求按请求时刻显示，状态提示明确说明它不是硬件确认；100 ms 内同 ID、同数据的硬件回读与先前请求配对去重。模拟采样单独标识。

每信号内部缓存最多 100,000 点，不显示缓存上限输入框；全部信号总预算 1,000,000 点，按信号数分配上限。新添加信号可回填当前保留的最近 10,000 条报文。GUI 最多约 30 Hz 刷新，每信号每个视窗最多绘制 1,000 点，按区间保留首尾及极值，缩放后依据当前视窗重新抽样；原始缓存及光标计算不按绘图抽稀。导入不同数据库后保留信号名称/颜色，清空旧采样并重新匹配，避免用旧解析结果混入新曲线。

信号可左键拖动排序，多选后右键创建一层命名组，单击组名重命名；组共用排序第一条信号的 Y 轴。相同数据库信号可多次添加，不同实例可属于不同组。Fit、arrange、All 都按组轴处理。

X 轴不显示负时间；X/Y 轴每五个小刻度为一个主刻度，主刻度标注数值，参考格以主刻度画虚线。缩放时动态选择时间或数值量级；枚举信号使用有效枚举值和名称。再次点击当前展示/坐标选项同样触发重绘。

## 开源调研与采用范围

- [vector_blf](https://github.com/Technica-Engineering/vector_blf)：BLF C++ 实现及对象布局参考，相关源码为 GPL-3.0-or-later，未链接或复制进本项目。
- [vblf](https://github.com/zariiii9003/vblf)：MIT，开发期 BLF 独立读回，覆盖正常 LIN 对象；部分错误类型只返回通用对象，测试额外核对其对象类型及字段。
- [python-can](https://python-can.readthedocs.io/en/stable/file_io.html)：开发期 ASC/BLF 的 CAN / CAN FD 独立读回。
- [Qwt](https://qwt.sourceforge.io/)：Qt 5/6 绘图库候选，原方案建议评估；最终使用 Qt 自绘以直接控制多 Y 轴、区域缩放和光标联动，不引入多轴分支。
- [SavvyCAN](https://github.com/collin80/SavvyCAN)、[PlotJuggler](https://github.com/PlotJuggler/PlotJuggler)：交互和时序展示参考，不整体移植。

## 验证方式

新增 trace_plot QtTest，覆盖时间与默认选项、模型树结构、同 ID 合并、半字节 10 帧渐变、历史上限、多个信号光标差、5 s 断线边界、逐帧采样、发送回读去重、坐标/展示模式、滚轮与删除，以及导出文件。

测试从本地 testsrc/test.asc 取前 3,000 条可识别 CAN/CAN FD/LIN 数据记录，生成 ASC、BLF 与独立比对清单。脚本核对 ID、数据、长度、通道、方向和时间：
```powershell
ctest --preset qt6 -R trace_plot --output-on-failure
python scripts/verify_trace_exports.py --artifacts C:/Documents/0_Qt/build/qttemp/Qt-GeneralController-qt6/tests/artifacts/trace --sample-blf testsrc/test.blf
```

开发验证脚本需要 python-can 4.6.1、vblf 0.3.1；它们不加入应用安装包。测试截图及导出样本仅写入相应构建目录。

Qt 5/6 配置、编译及部署路径固定为 C:/Documents/0_Qt/build/Qt-GeneralController-qt5 和 C:/Documents/0_Qt/build/Qt-GeneralController-qt6。独立解析器通过不能替代 CANoe 实机打开验证；本次不声称已完成 CANoe 或总线硬件验收。
