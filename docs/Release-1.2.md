# ReleaseVer: 1.2

界面版本为 ReleaseVer: 1.2，程序及 CMake 版本为 1.2.0。

## 主要变更

- 右键通道标题只保留通道配置入口和删除操作：未连接显示“连接通道”，已连接显示“修改通道”；左键双击打开相同的二级窗口。
- 连接/断开按钮移入“修改软件通道”窗口，在刷新硬件上方使用反转色。连接前应用当前草稿，实际连接由原软件通道持有，不会随关闭窗口断开。
- 窗口可在连接前后打开。连接时硬件设置和名称只读；断开后解除锁定。取消未应用的编辑仍不影响原通道。
- 载入配置、保存通道配置移入二级窗口，保留跨通道忙状态和硬件占用校验；载入配置先完成校验，关闭草稿后再替换真实通道。
- 主页面设备信息行最右侧显示硬件连接状态，左侧保留运行模式、设备、通道及波特率摘要。
- 同步界面、程序及打包版本，并更新交互回归测试和操作说明。

## 验证

构建目录保持为原工程上一级 `build/Qt-GeneralController-qt5` 和 `build/Qt-GeneralController-qt6`，本轮重新创建干净构建，使用此前固定版本依赖缓存。最终编译日志为 `release12-final-build.log`，完整回归日志为 `release12-final-tests.log`。硬件输入锁定断言随新交互更新后，交互测试的最终结果记录在 `release12-host-retest.log`。本轮不访问物理总线。


- Qt 5.15.19 和 Qt 6.8.4 发布编译完成，两套程序 `--version` 均输出 `GBoot 1.2.0`。
- 两套构建的 10 个测试套件最终均通过（各 256 条通过记录）；首次完整运行中旧的整体禁用断言失败，更新为硬件输入项锁定检查后，`host_ui` 单独重跑通过，其余 9 套件无需重跑。
- 交互覆盖：右键菜单随连接状态更新、双击打开同一窗口、连接按钮位置与样式、跨运行模式连接、断开后编辑、保存及载入配置、右侧连接状态。
- `testsrc/test.dbc`、`testsrc/test.ldf` 通过实际界面载入和模拟发送回归，并人工检查测试生成的主窗口、连接窗口及数据库页面截图。截图保存在各构建目录 `tests/artifacts`。
- MVVM 边界检查及 `git diff --check` 通过；物理 CAN/LIN 硬件测试未执行。
