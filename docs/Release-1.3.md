# Qt-GeneralController V1.3

程序、CMake 与 Windows 文件版本升级至 1.3.0。右下角 ReleaseVer 标记保持隐藏。

## 数据库导入兼容性补充

- 修复本地 DBC / LDF 的 GBK、GB18030 编码导入，保留 DBC 独立信号容器并禁止其参与总线收发。
- LDF 未引用编码中的非法 raw 区间改为明确提示，不再阻断有效帧导入；重复 ID 仍保留歧义保护。
- CDD 新增有符号范围及计数重复记录处理，验证 CANdela 16.0.3；取消高版本硬性白名单，改为兼容尝试、成功警告、解析失败报错。
- 新增本地批量导入与清单核对工具，Qt 5 / Qt 6 的 15 份数据库结果一致。业务文件及明细报告不随源码发布。
- README 说明项目使用 OpenAI Codex 开发。详见 [数据库导入验证](Database-Import.md)。

## 主要更新

1. 报文监视：t / rt / dt 独立控制列；默认仅显示 rt，以毫秒保留六位小数。按 ID 更新模式支持半字节变化着色、数据库信号展开及左对齐显示。
2. 发送工作台：支持无数据库新建 CAN 报文和 LIN 调度/帧、ID 修改与数据库默认值同步、多次发送/调度、周期发送/调度；默认周期 100 ms。
3. 日志与回放：支持 ASC / BLF、默认 BLF 文件名、日志通道多对一/多目标映射、模拟快速回放、真实硬件 1 倍速回放，以及使能报文覆盖和日志外报文追加。
4. 图像观测：信号列表、分组排序、差分光标、多轴布局、枚举刻度与网格、缩放、采样点和超过 5 秒断线；最多显示 1000 个采样点，按视口保形抽样。报文监视最多显示 10000 条。
5. 硬件：新增同星 TC1016 / TC1016P 的经典 CAN 和 LIN 适配，保留 PEAK 支持；本轮不提供真实 CAN FD 收发。
6. 配置与稳定性：统一保存项目配置、退出变更提示；修复 LIN 停止失败误报成功、导出请求/回显重复、ID 扩容未补零、接收校验类型、delay 撤销、已打开图像配置恢复和回放调度卡死。修复真实/模拟后端切换时旧通道被重新选中。
7. 构建：Qt 5 / Qt 6 程序目录仅放本体与运行依赖；所有构建、测试、调试和验证内容统一放在 `../build/qttemp`，默认 Release。

## 验证与边界

Qt 5.15.19 / Qt 6.8.4 均完成干净 Release 构建。两套各 14 项验证通过：13 项功能回归，加 1 项独立程序启动、三通道模拟下载与配置往返自检。首次新增自检继承了 offscreen 环境；隔离子进程环境后两套复测通过，正式程序无需携带测试插件。

两套 `--version` 均输出 `Qt-GeneralController V1.3 1.3.0`，Windows 文件版本为 `1.3.0.0`，产品版本为 `1.3.0`。在 PATH 不包含 Qt / MinGW 的条件下启动检查通过。

运行目录检查无测试 EXE、Qt Test、offscreen 插件或编译中间文件：Qt 5 为 23 个文件、约 29.43 MiB；Qt 6 为 29 个文件、约 61.18 MiB。必要 DLL、Qt 插件和硬件 API 属于程序运行依赖，需与 EXE 一同保留。

LIN1 连接真实 ECU，本轮不执行真实 ECU 收发。此前 TC1016P CAN1 / CAN2 回环验证通过；LIN 硬件相关故障路径由模拟 SDK 回归覆盖。文件格式中的 CAN FD 支持不代表真实硬件已开放 CAN FD。

MVVM 分层保持：硬件适配、调度和清理由基础设施/协议层执行，任务和配置由 ViewModel 管理，图像控件与交互留在 View。
