# Qt-GeneralController V1.4.1

## 更新

- 修复发送期间信号输入被刷新覆盖：减少无关状态触发的表格刷新，编辑委托保护尚未提交的 raw、物理值及枚举草稿；切换语言不再刷新组合框内部选择模型。
- 保持在线更新负载的现有通路与校验：提交后更新后续发送，非法值保留草稿并继续使用上一完整有效帧；结构编辑权限不变。
- 枚举 Y 轴保留物理坐标，已定义值显示名称，其余位置生成整数刻度和数值，参考格保持一致。带物理换算的枚举可在小数坐标显示名称，曲线和 dy 语义不变。
- 统一下载、UDS 诊断及信号发送页面底色；补充可翻译文件选择器的路径地址栏，支持粘贴目录或完整路径、中文和空格、带引号路径、回车定位和 Ctrl+L。
- rt 增加单位/精度提示，补充连续发送路径的时间回归：实际经过约 1 秒，时刻增量约 1000 ms。未再次除以 1000；六位小数末尾三个零符合整数微秒的采集精度。
- 同步中文主页、英文 README 链接、使用说明、资源版本和打包版本。

## 验证

Qt 5.15.19 与 Qt 6.8.4 的 Release 构建及全部 16 项 CTest 回归。新增测试覆盖持续收发/语言切换下的输入保留、更新负载、时刻与实际经过时间比例、带小数物理值的枚举刻度、五类文件路径粘贴及统一背景。

实机 CAN 回环验收启动时未枚举到设备，用户随后确认真实测试设备已移除；未发送实机测试帧，未执行 LIN ECU 测试。真实在线 rt 问题需设备重新接入后核验，不能用模拟结果代替实机验收。手动测试工具仅位于 qttemp 的 tests 中，不进入程序运行目录或 CTest。

MVVM：输入保护、文件选择和轴刻度属于 View；Qt 展示模型减少无关刷新，合法提交仍经 ViewModel/SignalCodec/worker 到发送器。协议与硬件层未引入界面依赖。
