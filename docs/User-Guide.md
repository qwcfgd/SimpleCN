# 使用说明

启动 QtBootloader.exe，在左侧软件通道标题列空白处右键选择“新建通道”，在二级配置窗口选择 CAN / LIN、运行模式、硬件设备、硬件通道、波特率及自动重连。选择模拟模式后连接通道，即可载入模拟镜像进行协议验证。

未连接时右键通道标题显示“连接通道”，已连接时显示“修改通道”，均打开同一个“修改软件通道”窗口；左键双击标题也可打开。窗口中的反转色“连接设备 / 断开连接”按钮位于“刷新硬件”上方。点击连接会先应用当前名称和硬件设置，再连接实际软件通道；该操作已应用的设置不会因随后取消窗口而回退。未点击连接或保存时，取消仍丢弃草稿。

窗口在连接前后均可打开。已连接或正在处理连接时，硬件参数和名称锁定；断开并处理完成后可继续修改。载入配置、保存通道配置均在此窗口中，保存覆盖全部软件通道；载入前需要断开全部通道。没有通道时可从标题列空白处右键“新建通道”，在该窗口中载入配置。

标题列底部保留一行新建空白区域；滚轮浏览不会切换通道。每个通道包含“下载”“UDS 诊断”“信号发送”三个子页，顶部左侧显示运行模式、硬件选择、硬件通道和波特率，最右侧显示硬件连接状态。诊断页可载入不同 CDD，选择 ECU / Variant 并生成服务列表、参数及请求 HEX，详见 [CDD 自动配置与 UDS 诊断](CDD-UDS.md)。


## 信号发送 · 报文工作台

点击“通信配置…”导入 UTF-8 DBC/LDF，设置 CAN 节点及方向，或 LIN 角色、节点与调度表，完成后点击“确认”。数据库只读。DBC 树按节点下的 Rx、Tx 分组浏览；选择发送节点或方向时替换数据库报文，保留自建报文。

- CAN：列表初始为空。选择节点报文，或在列表空白处右键“自建报文”；右键已有行可删除。勾选“使能”后可单次或周期发送，周期至少 1 ms，0 表示仅单次。自建 ID 不得与当前库或其他自建报文的数值 ID 重复；0–0x7FF 为标准帧，其余合法 ID 为扩展帧。
- LIN：选择主节点、具体从节点或监听。主节点执行调度，从节点只响应本节点发布且在所选表内的使能帧，监听不响应。停止后可编辑调度结构；运行中可通过列表上方或通信配置中的下拉框切表，当前帧完成后从新表首帧开始。
- 两张发送表的第一列为使能，取消勾选仍可编辑配置。发送中改变勾选状态，当前轮全部完成后在下一轮应用；全部取消后任务空闲，可重新勾选恢复。从节点需外部主节点提供完整调度轮次的接收事件。
- 在“报文”列修改完整 HEX，或在下方信号表直接修改发送 raw、发送物理值；存在枚举时物理值单元格提供下拉选择。初始 raw 与注释只读并标灰。回车或失焦提交，非法输入保留错误草稿，发送继续使用上一完整有效帧。
- “回退”返回上一步编辑，“撤销”恢复最近导入或全局配置恢复后的基准。全局通道配置保存列表、有效值、勾选状态与调度设置；读取、重启、重连均不会自动发送。独立信号初值/配置文件窗口已移除。

同一软件通道的信号发送与下载、UDS、扫描互斥；不同通道可独立运行。仿真不访问物理总线，也不会伪造外部 ECU 响应。首版支持范围与未验收事项见 [实施记录](Signal-Transmission-Implementation.md)。

## 报文监视与图像观测

报文监视中的 t / rt / dt 分别控制系统时间、从 0 s 起算的时刻和相邻记录时间差（秒），初始仅显示 rt。“滚动显示”默认关闭；开启后相同 ID 原位更新，数据按半字节比较，连续相同 10 帧渐变为灰色。已导入数据库的报文可展开查看信号值。导出支持 ASC、BLF、CSV，范围为启动或上次清空后的全部历史记录。

在信号发送页点击“图像…”打开观测窗口，右键添加当前通道数据库信号。支持 Shift 多选、Delete 删除、手动改色、All / Marked / GrayNoMarked 展示，以及 Fit / arrange / All 坐标布局。两个光标对每个信号独立计算 y(C2) − y(C1)；超过 5 s 的采样空档断线且不插值。详细操作与验证范围见 [报文监视与图像观测](Trace-and-Graphics.md)。

## 模拟下载

源码示例配置位于 profiles/；编译后的测试素材位于 ../build/qttemp/Qt-GeneralController-qtN/tests/profiles/，发布包不携带模拟测试素材。镜像相对路径以配置文件目录解析。测试固件只用于模拟，不能写入实际设备。

下载镜像与下载任务上下排列，开始下载、取消和进度条位于同一行。APP / Boot 流程、步骤反馈、超时、镜像基址和 RID / DID 可在下载设置中配置。公开默认值是示例值；真实目标参数需要单独填写并保存至本地配置。

## 外部安全访问算法

公开仓库和公开发布包不包含任何私有算法 DLL 或真实 seed/key 向量。simulation 使用模拟算法；online 下载要求明确提供已授权的外部 DLL，缺少 DLL 时不启动下载。

通用外部提供者标识为 external-generatekeyex。旧配置需要在下载设置中重新选择提供者并保存。DLL 相对路径以 EXE 目录解析。可选桥接程序位于 seedkey/SeedkeyBridge32.exe，使用 GenerateKeyEx 接口；接口位数、参数约定和输入长度限制必须与使用者提供的 DLL 兼容。

为保护本地目标参数，请将实机配置、算法 DLL 和验证记录保存在 private/ 或仓库外。公开打包脚本不携带这些资料。

## 发布自检

使用清洁构建生成公开包。自检程序留在 qttemp，使用 CTest 运行：

```powershell
ctest --preset qt6 -R release_runtime
# Qt 5 使用 qt5；自检结果在 qttemp 下的 tests 目录。
```

设置 HOST_RELEASE_DIR 环境变量可指定另一份发布目录。自检只验证启动、模拟下载和配置保存，不调用私有算法或物理总线。输出中可能包含本机路径，不应直接上传。

## 硬件模式

硬件通信需要匹配的 PEAK 驱动或同星 TSMaster 运行库。同星 TC1016/TC1016P 的使用与验证范围见 [同星硬件适配](Tosun-Hardware.md)。online LIN 下载前需配置实际 NAD、会话、安全级别、时序、例程和镜像地址。CAN 下载目前仅支持 simulation。默认值和模拟通过结果不能替代实机适配与验证。

配置初值位置见 [默认配置](Default-Configuration.md)。


信号发送、日志回放和项目配置的新操作见 [信号工作台与日志回放](Signal-Workbench-Replay.md)。

## V1.4：语言、表格与枚举编辑

- 主标题右侧的简中 / Eng 立即切换界面语言，重启后保留选择。数据库中的名称、枚举标签及用户输入不翻译。
- 在 CAN 待发送报文、LIN 待发送帧和信号表中，拖动表头边缘调整列宽，左键按住表头拖动调整顺序；点击保存项目配置可保存各通道布局。
- 单击发送 raw 或发送物理值即可编辑。枚举下拉可输入名称，自动补全后按 Tab 接受；也可直接修改 raw 为未定义枚举值，此时枚举显示“-”，实际发送值仍受信号位宽与编码校验约束。仅含枚举且没有物理换算的下拉允许输入数值，按 raw 处理。
- 图像页 arrange 在当前高度内排列所有信号组，不出现垂直滚动条。枚举 Y 轴刻度随缩放调整，已定义枚举位置显示名称，其他刻度显示整数；保留物理坐标，参考格跟随主刻度。左侧 y 列命中枚举时显示名称，dy 保持数值差。
- 报文 rt 单位为 s，省略小数末尾的 0；微秒时间戳除以 1000000，记录起点归零。

## V1.4.1：发送中编辑与路径输入

发送中编辑的内容在回车、Tab 或失焦前保留，不受帧接收、发送计数或语言切换刷新影响；合法值提交后更新后续报文，已进入硬件队列的报文可按旧值完成。非法输入不替换最后一帧有效数据。ID、周期、帧长度及数据库结构仍在停止后修改。

V1.4.1 添加的文件路径栏已在 V1.4.2 删除，当前操作方式见下文。

当前 rt 与 dt 均采用 s。微秒采集值除以 1000000 后显示，例如 `0`、`1`、`1.00125`、`1.200123674`；小数末尾的 0 省略，整数部分的 0 保留。底层采集、回放和 ASC / BLF 时间记录仍使用原有精度，CSV 的 rt 列与监视显示一致。


## V1.4.2：现代原生文件选择

所有文件打开 / 保存入口使用 Windows 现代原生对话框。目录可输入系统自带地址栏；完整文件路径可粘贴到“文件名”输入框，再点击打开或保存。中文和空格路径交由系统处理，文件类型下拉保留各入口原有扩展名筛选。取消后不更改文件选择或执行导入 / 导出。报文导出继续按所选 BLF / ASC / CSV 类型处理。

不再提供额外的顶部路径栏、“转到”按钮或应用自定义路径定位逻辑。对话框中的系统按钮、地址导航、覆盖确认及错误提示使用 Windows 的语言设置；应用提供的任务标题随简中 / Eng 切换，其他界面语言切换不变。


## 完整缓存与暂停历史浏览

程序保留启动或上次点击“清空”之后的全部报文，导出不受表格 10,000 条显示上限影响；关闭程序后缓存清空。“暂停更新”默认关闭，开启时仅暂停画面，后台记录继续。缓存超过 10,000 条时拖动表格左侧历史滚动条，可切换到任意位置的连续 10,000 条；右侧滚动条浏览该窗口内部。关闭暂停后返回最新数据，跟随开启时自动到底部。暂停、数量和区间提示支持简中 / Eng，详细交互见 [报文监视](Trace-and-Graphics.md)。
