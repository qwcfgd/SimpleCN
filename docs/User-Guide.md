# 使用说明

启动 QtBootloader.exe，在左侧软件通道标题列空白处右键选择“新建通道”，在二级配置窗口选择 CAN / LIN、运行模式、硬件设备、硬件通道、波特率及自动重连。选择模拟模式后连接通道，即可载入模拟镜像进行协议验证。

右键已有通道时依次显示“修改通道”“删除通道”。修改窗口仅在确认后应用到当前通道，取消保留原配置；修改前需要断开当前通道并等待操作结束，已创建通道的总线类型固定。标题列底部始终保留一行新建空白区域，通道过多时使用鼠标滚轮浏览，不改变当前选中的通道。

每个通道依次包含“下载”“UDS 诊断”“信号发送”三个子页，共用上方连接状态、连接按钮和下方报文监视、运行日志。“UDS 诊断”页可载入不同 CDD，选择其中的 ECU / Variant，自动生成服务列表、参数表和请求 HEX。详细操作及兼容范围见 [CDD 自动配置与 UDS 诊断](CDD-UDS.md)。

## 信号发送

点击“通信配置…”打开二级窗口：CAN 通道导入 UTF-8 DBC，LIN 通道导入 UTF-8 LDF。数据库路径、解析摘要与诊断文本、重新加载、自建 CAN 编辑、LIN 角色/节点/调度设置、回退和撤销均在此窗口中。主页面保留数据库浏览表、发送报文/帧表、所选发送帧的 raw 和信号值表，以及发送/停止操作。导入和重新加载只读取源文件，不改写数据库。节点树用于浏览，发送选择由右侧 CAN 启用列或 LIN 角色、节点与调度表决定。

- CAN：勾选报文后单次或周期发送。周期为至少 1 ms 的整数；0 表示仅单次。自建报文只编辑帧 raw，ID 不得与当前通道任何数据库或自建报文的数值 ID 重复；0–0x7FF 始终为标准帧，其余合法 ID 为扩展帧。
- LIN：运行前选择主节点、具体从节点或监听。主节点执行调度；从节点只响应“本节点发布且在所选表内”的帧；监听不发送或响应。运行时角色和结构冻结，主/从角色仍可编辑所有帧副本，未参与发布的修改只保存在本地。
- 修改信号 raw、物理值或帧 HEX 后，回车或失焦提交。位宽溢出显示红色错误草稿，后续发送继续使用上一完整有效帧；数据库 min/max 越界但位宽可表示时允许应用并显示警告。物理值量化向零截断，显示实际值及差异。
- “通信配置… → 信号初值 / 配置文件…”中的默认值只读，信号有效位全 1。文件初值只覆盖可编辑使用值，使用值与主页面共用数据。RX 独立显示，未收到时保持“未接收”。
- 停止后可编辑 LIN 调度结构。主节点运行中切表等待旧表整轮结束；从节点切表暂停响应、替换集合再恢复。日志区分硬件事件间隔、主机配置耗时和模拟估计。
- “回退”返回上一步编辑；“撤销”恢复最近读取的通信配置，未读取过则恢复最近导入后的状态。保存不改变撤销基准。读取、重启、重连都不会自动开始发送。

同一软件通道的信号发送与下载、UDS、扫描互斥；不同通道可独立运行。仿真不访问物理总线，也不会伪造外部 ECU 响应。首版支持范围与未验收事项见 [实施记录](Signal-Transmission-Implementation.md)。

## 模拟下载

源码示例配置位于 profiles/，发布包使用 profiles/simulation.json。镜像相对路径以配置文件目录解析。测试固件只用于模拟，不能写入实际设备。

APP / Boot 流程、步骤反馈、超时、镜像基址和 RID / DID 可在下载设置中配置。公开默认值是示例值；真实目标参数需要单独填写并保存至本地配置。

## 外部安全访问算法

公开仓库和公开发布包不包含任何私有算法 DLL 或真实 seed/key 向量。simulation 使用模拟算法；online 下载要求明确提供已授权的外部 DLL，缺少 DLL 时不启动下载。

通用外部提供者标识为 external-generatekeyex。旧配置需要在下载设置中重新选择提供者并保存。DLL 相对路径以 EXE 目录解析。可选桥接程序位于 seedkey/SeedkeyBridge32.exe，使用 GenerateKeyEx 接口；接口位数、参数约定和输入长度限制必须与使用者提供的 DLL 兼容。

为保护本地目标参数，请将实机配置、算法 DLL 和验证记录保存在 private/ 或仓库外。公开打包脚本不携带这些资料。

## 发布自检

使用清洁构建生成公开包。在解压目录运行：

```powershell
.\VerifyRelease.exe -o verification-results.xml,xml
```

自检只验证启动、模拟下载和配置保存，不调用私有算法或物理总线。输出中可能包含本机路径，不应直接上传。

## 硬件模式

硬件通信还需要匹配的 PEAK 驱动及授权通信模块。online LIN 下载前需配置实际 NAD、会话、安全级别、时序、例程和镜像地址。CAN 下载目前仅支持 simulation。默认值和模拟通过结果不能替代实机适配与验证。

配置初值位置见 [默认配置](Default-Configuration.md)。
