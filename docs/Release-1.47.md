# SimpleCN 1.47

本版保留现有下载与报文观测功能，更新下载设置及 T008 传输，并改进筛选后的暂停、交替背景和滚动定位。

CAN 下载在收到 CTS、且接收端 STmin 为零时，连续帧最多允许四帧已提交但尚未收到发送回显；其他帧及非零 STmin 仍逐帧确认。窗口受接收端 BS、发送确认和传输故障约束，驱动接受发送请求不等于总线已发送。用户已实测下载并接受当前速度；具体速度取决于总线和设备。

复位等待时间仍使用下载配置中的值。CAN 总线告警使用黄色；不增加全局 BUSOFF 自动重试或控制器硬复位。对已提交但结果不明的诊断发送，用户可按提示手动断开并重连后重新开始；旧请求仍可能已经执行。UDS 没有事务标识，对同一请求的迟到响应不能保证完全消歧。

本版未包含双区 Boot 更新功能；后续适配另行发布。
