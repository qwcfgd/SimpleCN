# Qt-GeneralController V1.4

## 更新

- 主标题右侧新增无标题的简中 / Eng 下拉框，实时切换应用界面、弹窗、表头、提示和动态状态，记住语言选择。数据库与用户内容不翻译。
- CAN 待发送报文、LIN 待发送帧、报文信号表支持用户调整全部列宽和拖动列顺序，按软件通道保存到项目配置。
- 信号发送 raw / 物理值支持左键单击进入编辑，保留只读和角色权限约束；枚举支持文本输入、自动补全及 Tab 接受，未定义原始值可以发送，枚举标签显示“-”。
- 图像画布禁止垂直滚动，arrange 布局按当前高度分配各组；枚举刻度与参考格按缩放调整，未命中枚举的刻度不显示文本。
- 图像 y 列在最新值或光标值命中枚举时显示枚举名称；双光标差值仍使用数值计算。
- 修正文本型小数微秒时间戳的 rt 显示：1200123.674 μs 显示为 1200.123674 ms，记录起点仍归零。

## 架构及构建

语言服务及控件翻译属于显示层，业务模型、发送负载及数据库内容保持原始值。表格布局由 View 采集，通过 ViewModel 的项目配置接口保存；图像枚举显示不改变采样及差值计算。

Qt 5 / Qt 6 程序本体分别位于 ../build/Qt-GeneralController-qt5 与 ../build/Qt-GeneralController-qt6；编译、测试、截图及调试内容位于 ../build/qttemp。

本项目使用 OpenAI Codex 协助开发。真实 LIN ECU 验收范围沿用此前说明，本次验证不发送硬件测试帧。

## 验证结果

Qt 5.15.19 / Qt 6.8.4 Release 构建通过，两套各 15 项 CTest 验证通过。新增回归覆盖 900 余项翻译及占位符、实时语言切换、输入保留、动态弹窗、CAN/LIN 表头鼠标拖动与配置恢复、单击编辑、枚举 Tab 补全、未定义 raw 编码、枚举光标差值、LIN 纯枚举绘图、微秒换算和多图高度适配。

Qt 5 首次拖动测试未携带按住的鼠标键状态；改用显式 LeftButton 移动事件后，Qt 5 / Qt 6 均通过。两套 Windows 文件版本为 1.4.0.0，产品版本为 1.4.0；程序目录检查无测试 EXE、Qt Test、offscreen 插件或编译中间文件。
